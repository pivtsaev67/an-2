# AN-2 — редизайн интернет-магазина

Новый фронтенд для [an-2.ru](https://an-2.ru): дизайнерская женская одежда AN-2 и Natalia Slavina.

## Что внутри

- **3D-примерочная 360°**. Каждый товар показывается в 3D на портновском манекене: вращение мышью или пальцем, зум колесом, автоповорот, полноэкранный режим, плавная смена цвета. Фактура ткани (шерсть, твид, шёлк, кружево, фетр, замша, креп) генерируется процедурно.
- **Все функции магазина**: каталог по категориям, «Новинки», Sale, фильтры (бренд, размер, цвет, цена), сортировка, карточка товара (цвет, размер, количество), таблица размеров, корзина, оформление заказа, «Купить в 1 клик», избранное, «Вы смотрели», поиск (`/` или `Ctrl+K`), личный кабинет, обратный звонок, подписка. Есть страницы «О компании», «Как купить», «Контакты» с картой.
- **Эффекты**: бегущие строки, появление блоков при прокрутке, 3D-наклон карточек, «магнитные» кнопки, кастомный курсор, анимация полёта товара в корзину. Учитывается настройка `prefers-reduced-motion`. Вёрстка адаптивная, от 360 px.

## Запуск

Статический сайт без сборки:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

three.js лежит в `vendor/`, поэтому внешние CDN для работы не нужны.

## Как добавить настоящие 3D-модели или фото 360°

У товара в `js/data.js` есть два необязательных поля:

```js
model:  'assets/models/plate-dvubortnoe.glb',   // 3D-модель
frames: ['assets/360/plate/01.jpg', /* … 36 кадров … */], // фото на поворотном столе
```

- **`.glb`**: экспорт из CLO3D, Marvelous Designer или Blender. Модель сама отмасштабируется и встанет на пол. Рекомендации: до 50–80 тыс. полигонов, текстуры 2K, сжатие Draco или Meshopt.
- **Фото 360°**: 24–36 кадров с шагом 10–15°, одинаковый фон и свет. Можно и рендер turntable-анимации.
- Если ни одного поля нет, показывается процедурная модель по полям `type` и `fabric`.

## Подключение к WooCommerce

Текущий сайт работает на WordPress + WooCommerce (URL вида `/product-category/…`, `/shop/…`). Варианты интеграции:

1. **Headless**: `js/data.js` заменяется загрузкой из Store API (`/wp-json/wc/store/v1/products`), а `sendOrder()` в `js/app.js` — на `POST /wp-json/wc/store/v1/checkout`.
2. **Тема WordPress**: разметка и стили переносятся в дочернюю тему, 3D-просмотрщик подключается на шаблоне `single-product`.

В статической версии заказы, «1 клик» и обратный звонок открывают письмо на `shop@an-2.ru` с заполненными данными. Корзина, избранное и профиль хранятся в `localStorage`.

## Данные каталога

`js/data.js` генерируется скриптом `scripts/import_wp.py` из `data/wp-products.json`, публичной выгрузки
`https://an-2.ru/wp-json/wp/v2/product?per_page=100`. Сейчас это 100 товаров.

- **С сайта**: названия, категории, адреса, описания, составы, даты. Из текста описаний извлекаются цвет, длина рукава, пуговицы, молния и пояс, а из названия и состава — фактура ткани для 3D.
- **Оценочно** (в этом API данных нет): цены (`priceEstimated`, по диапазонам категорий), размеры, цвет, если он не указан в описании.
- **Фото**: сохраните ту же ссылку с `&_embed` (`...?per_page=100&_embed`) в `data/wp-products.json`, и скрипт подхватит ссылки на изображения.
- Если товаров больше 100, сохраните `&page=2` как `data/wp-products-2.json`.

Обновить каталог: `python3 scripts/import_wp.py`.
